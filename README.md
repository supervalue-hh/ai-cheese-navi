# AIチーズナビ

店頭タブレット用のチーズ案内キオスクアプリ。
チーズを選ぶと、味わいの説明と「どんな料理・食べ方に合うか」を紹介します。

日本マイセラ株式会社の European Cheese Selection カタログ（2025年6月版）掲載の225品目を収録。

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（単一ファイル・依存なし） |
| `cheese_data.js` | チーズ商品データ（`var CHEESE_DATA = [...]`、225品目） |
| `robots.txt` | 検索エンジンブロック（社内方針） |
| `serve.js` | ローカル確認用の簡易HTTPサーバー（`node serve.js` → http://localhost:8787） |

## 主な機能

- 50音キーボードでのチーズ名検索（濁点・小さい文字・長音なしでもヒットするゆるやか照合）
- 種別（白カビ／青カビ／ウォッシュ等）での絞り込み
- チーズ詳細カード：種別・産地国・原料乳・味わい・相性の良い食べ方
- 無操作2分で最初の画面に自動リセット（店頭キオスク向け）
